# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | lists the files and directories in current directory |
|     cd directory_name       | changes current directory to directory_name if directory_name is one level down or if path is specified |
|     cd ..                   | changes current directory to it's parent directory (one level up) |
|     cd -                    | goes back to the last directory (sort of like a back button) |
|     mkdir directory_name    | mkdir means make directory - it creates a new empty directory one level down in current directory with the name directory_name |
|     touch filename          | creates a new and empty file inside the current directory with the name filename with any extension |
|     git status              | shows status of my codespace and what is yet to be committed from my codespace to GitHub and what's yet to be staged |
|     git add -A              | stages changes, let's git knows changes ahve been done, -A means all |
|     git commit -m ""        | bundles changes into a commit, sort of like a checkpoint, -m is followed commit message in double quotes, which is compulsory |
|     git push                | saves changes to Github server |
|     git pull                | pulls changes from my repo to codespace |
